# 달빛 사주 — AI 사주 상담 웹 서비스

기획서(기능/프롬프트 + 웹 디자인 UI/UX)와 사주 계산 기술문서를 그대로 구현한 MVP입니다. 로그인·결제 없음.
**외부 패키지가 없습니다**(Node 18+ 만 필요).

## 실행
```bash
cp .env.example .env     # OPENAI_API_KEY 입력 (없으면 데모 모드)
npm start                # http://localhost:3000
npm test                 # 만세력 엔진 검증
```

## 구조
| 파일 | 역할 |
|---|---|
| `lib/saju.js` | 만세력 엔진: 연·월·일·시주, 오행, 십성, 지장간, 대운/세운, 충·합, 음력/윤달 |
| `lib/prompt.js` | 기획서 시스템 프롬프트 + 계산값 주입(서비스/페르소나 분기) |
| `lib/demo.js` | API 키 없을 때 쓰는 규칙 기반 데모 풀이 |
| `server.js` | `/api/saju`, `/api/interpret`(SSE 스트리밍), 정적 서빙, 요청 제한 |
| `public/` | 모바일 우선 다크 UI (3단계 입력 → 로딩 → 결과 리포트) |

## 계산 방식 (기술문서 기준)
- 연주: 입춘(태양황경 315°) 기준, `(Y-4) mod 10/12`
- 월주: 12절 절입 기준(태양황경으로 판정) + 연두법
- 일주: JDN 기준 60갑자 (1900-01-01 甲戌 검증)
- 시주: 2시간 12지지 + 시두법
- 옵션: 동경시 보정(-30분, 시주·일주에 적용), 자시 처리(조자시/야자시)
- LLM에는 서버가 계산한 간지·오행·십성·대운·세운만 전달해 만세력 환각을 막습니다.

## 알아둘 한계
- 절입시각은 태양 황경 천문 계산이라 공표 절기표 대비 **최대 약 10분 오차**가 있습니다. 절입 ±30분 이내 출생은 화면에 경고를 띄웁니다. 정밀 서비스는 한국천문연구원 절기표 DB로 교체 권장.
- 과거 한국의 표준시 변경(1954~61년 UTC+8:30)과 서머타임(1948~51, 55~60, 87~88년)은 반영하지 않았습니다.
- 신강/신약은 단순 참고 지표이며 정식 용신 판정이 아닙니다.
- 지원 범위 1900~2100년.
